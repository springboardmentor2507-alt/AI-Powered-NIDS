SentinelNet: AI-Powered Network Intrusion Detection System (NIDS)
#http://localhost:8501/

With the rapid growth of digital infrastructure and network-based applications, cybersecurity threats have become increasingly sophisticated and frequent. Traditional security mechanisms such as firewalls and signature-based intrusion detection systems (IDS) are often insufficient to detect modern and evolving cyberattacks. These systems rely heavily on predefined rules and known attack signatures, making them ineffective against zero-day attacks and novel intrusion patterns.

SentinelNet is an AI-powered Network Intrusion Detection System (NIDS) designed to intelligently monitor network traffic and detect malicious activities in real time. The system leverages machine learning and anomaly detection techniques to analyze network behavior, identify abnormal patterns, and classify potential intrusions with high accuracy. By learning from historical data, SentinelNet adapts to changing network conditions and improves its detection capabilities over time.

The project utilizes the NSL-KDD dataset, a benchmark dataset for intrusion detection research, to train and evaluate both supervised and unsupervised machine learning models. Various preprocessing techniques, feature engineering methods, and classification algorithms are applied to enhance detection performance while minimizing false positives. SentinelNet is capable of identifying multiple categories of attacks such as DoS, Probe, R2L, and U2R.

SentinelNet aims to provide a scalable, efficient, and intelligent security solution for modern networks. By integrating AI-driven analytics with real-time alerting and logging mechanisms, the system assists network administrators in proactively detecting threats, responding to intrusions, and strengthening overall network security posture.
